# PCAP Records

`pcap_records/` 디렉터리는 캡처된 PCAP 파일을 보관하기 위한 공간입니다.  
실험, 디버깅, 분석 과정에서 수집된 네트워크 패킷 트레이스를 저장하는 저장소 역할을 합니다.

## 목적
- 원본 패킷 캡처 파일을 보존하여 이후 참고 가능
- 네트워크 분석 및 문제 해결을 위한 재현 가능한 데이터 제공
- 테스트 세션 및 모니터링 활동의 기록을 체계적으로 관리

## 작성 규칙
- 파일 이름은 날짜와 상황을 포함해 설명적으로 작성 (예: `2026-04-18-login_test.pcap`)
- 원본 캡처 파일만 저장하고, 분석 결과는 `pcap_analysis/`에 기록
- 파일은 바이너리 PCAP 형식(`.pcap` 또는 `.pcapng`)으로 유지
- 새로운 캡처를 추가할 때마다 이 인덱스를 업데이트
